# Linux Support & Diagnostics Lab

A collection of practical troubleshooting runbooks and Bash scripts used by Support Engineers to diagnose and resolve Linux server issues.

## 🎯 Purpose
This repository simulates real-world incidents that a Cloud or Application Support Engineer faces daily. Each runbook follows a standard incident response structure: **Incident Summary → Diagnosis → Resolution → Verification**.

## 📂 Repository Structure
- `playbooks/`: Step-by-step guides for resolving specific Linux issues.
- `scripts/`: Bash scripts for automating routine checks.

## 🛠️ Skills Demonstrated
- **Linux System Administration:** Managing services (`systemctl`), users, and permissions.
- **Log Analysis:** Debugging issues using `grep`, `tail`, and `journalctl`.
- **Networking:** Troubleshooting connectivity with `curl`, `ping`, and `ss`.
- **Automation:** Writing Bash scripts for proactive monitoring.

## 🚀 How to Use
Each file in the `playbooks/` directory represents a specific scenario. You can read through them to see how I diagnose and resolve issues.
